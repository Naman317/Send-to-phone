Step 1

Create Your Telegram Bot

Create a Telegram bot to send files.

1 Open Telegram and search for @BotFather
2 Send the command /newbot
3 Follow the prompts and choose a bot name and username
4 Copy the token provided by BotFather

Step 2

Find Your Chat ID

Specifies the destination chat for downloads.

1 Open Telegram and search for @userinfobot
2 Press Start to get your ID
3 Copy the Id number
4 Send a message to your bot once so it can contact you
Files over 50 MB cannot be sent due to Telegram Bot API limits.
